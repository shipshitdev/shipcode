# @shipcode/ui

ShipCode-specific UI for the ShipCode monorepo.

## Boundary

- Use `@shipshitdev/ui` for shared primitives, icons, layout, and generic workflow UI.
- Use `@shipcode/ui` only for ShipCode domain UI such as the ShipCode kanban, plan/review/diff viewers, pipeline phase chips, and ShipCode branding.

## Current Surface

- `ActivePipelineCard`
- `DiffViewer`
- `KanbanBoard`
- `PhaseChip`
- `PipelineStatus`
- `PlanViewer`
- `ReviewViewer`
- `SideBySideDiffViewer`
- `StatusMappingEditor`
- `VerificationViewer`
- `ShipCodeLogoMark`
