### What Was Done

- Deleted React Doctor suppression/config work. The session explicitly fixed warnings in source instead of hiding them.
- Removed Recharts from desktop chart/gauge paths:
  - CPU gauge in `Titlebar` moved to DOM/CSS.
  - Cost charts moved to lightweight DOM/CSS chart components.
  - Removed `apps/desktop/src/renderer/components/ui/chart.tsx`.
- Removed delayed terminal unmount hook and related tests:
  - Deleted `useDelayedUnmount`.
  - Rendered terminal drawer directly from visible state.
- Refactored large desktop renderer components into hook-backed view wrappers and smaller helpers to satisfy React Doctor without changing user-facing behavior.
- Replaced reset-heavy `useEffect` patterns with keyed derived state or reducers:
  - `SkillsView` editor draft derives from selected row unless dirty.
  - `InboxView` paging is keyed by filter/sort scope.
  - `ProjectSettingsModal` project/setup seed state is reducer-backed.
  - `CreateIssueModal` draft state is reducer-backed.
  - `PipelineTab`, `IssueDetail`, and `IssuesPanel` grouped local UI transitions into reducers.
- Fixed `useIpc` false-positive cascading-state warning by renaming Zustand action bindings away from React-style `set*` local names.
- Cleaned up repo-level React Doctor warnings in `packages/ui`:
  - `KanbanBoard` wrapped in a hook-backed view and reduced state warning surfaces.
  - `IssueCardParts` extracted warning-prone components/helpers and combined label filtering/mapping.
- Fixed typecheck issues uncovered during verification:
  - Narrowed failed GitHub sync result handling.
  - Corrected `CreateIssueModal` edit draft type.
  - Updated `IssueDetailDialogs` test for `buildIssueDetailDialogs`.
  - Stabilized nullable update dismiss and manual QA server references.
  - Removed stale exported `ViewMode` type surface.

### Key Decisions

- Real fixes only: no React Doctor config, no suppressions, no warning hiding.
- Keep Recharts out of the CPU gauge path because upcoming tooltip work should not inherit a charting dependency.
- Prefer reducer/keyed-state refactors for repeated reset effects instead of adding presentation guards or legacy fallback states.
- Leave unrelated dirty worktree changes alone; this session worked with the existing dirty repo without reverting user/generated edits.
