### Key Decisions

1. **Breadcrumb placement in bridge** — between event-log write and failure capture, so the trail lands before the failure capture's Sentry call and attaches to it.
2. **Breadcrumb events** — only `start-context`, `phase`, `approval-gate`, `verification-exhausted` → null for noisy per-turn/per-model events. Keeps signal-to-noise high.
3. **Native labels vs board-only** — core bug in #45: `metadataLabels` was hardcoded `[]`, so complexity/blast only reached Projects v2 board fields (vanishing for boardless projects). Fix: always derive from `prdMetadata` and merge.
4. **Frontmatter strip in pipeline** — one-line `stripPrdFrontmatter(issue.body)` call in `startFromGitHubIssue` prompt builder (AC5 of #45). Tested via existing unit-tested pure fn, not brittle integration test.
5. **#18 architecture**: Terminal-tab TerminalPane (not TerminalDrawer — it's output-only), fenced ` ```prd ` block extraction (option 1+2 from issue).
