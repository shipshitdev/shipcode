### Mistakes and Fixes

- **Direct `tsc`/turbo failed locally after branch switch** — `tsc: command not
  found` / missing node types. Cause: deps not installed for the checked-out
  branch. Fix: `bun install`, then turbo reproduced the exact CI error. Lesson:
  reproduce CI typecheck via `bunx turbo run typecheck --filter=<pkg>` after
  `bun install`, not bare `tsc` (turbo injects the env/types).
- **`bun run test <path>` doesn't work** — repo `test` script is turbo-wrapped and
  rejects file-path args. Use `bunx vitest run <pattern>` inside the package.
