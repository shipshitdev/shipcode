### Key decisions

- **Root imports + bundler alias over source-everywhere.** Converting /source →
  root touches 27 files; the reverse (all-source) would touch hundreds and break
  e2e's node-resolution of package dists. Desktop keeps its ui-only source alias
  (deliberate, for HMR); every package now resolves exactly one way per bundle.
- **Node 24 in publish-cli kept.** Not drift — npm OIDC/provenance publishing
  needs npm ≥ 11.5 (Node 22 ships npm 10). Documented inline instead of "fixed".
- **Coverage floor raised, not lowered.** CI's 80/80 was the stale value; the
  95/90 release contract is documented and the last snapshot passes it.
- **Branch protection untouched.** New Build job must go green once before being
  added to required checks (repo-settings change, Vincent's call).
- **UI libraries are layered, not duplicated** (Vincent correction): published
  `@shipshitdev/ui` = cross-project primitives; `packages/ui` = ShipCode feature
  components. Audit report corrected; follow-up session 01 descoped accordingly.
- **Unsigned macOS + notify-only updater accepted** for the pre-release phase.

### Mistakes and fixes

- **Blind sed created duplicate mock specifiers.** Converting
  `vi.mock('@shipcode/db/source')` → `vi.mock('@shipcode/db')` in files that
  already mocked the root produced two mocks of the same module (last one wins →
  `getDatabase` undefined). Caught by tests in 3 files; merged blocks. Lesson:
  after mechanical import rewrites, scan test files for duplicate mock specifiers.
- **Parallel local test runs poisoned each other.** Running the desktop suite
  while another suite/typecheck ran produced rotating renderer-test failures
  (25–148s per file, different set each run). All 10 "failures" pass on an idle
  machine; main-process tests (actual blast radius) pass deterministically.
  This machine (Mac14,7) is not the Mac Studio — full gates belong to CI anyway.
- **First audit workflow burst rate-limited.** 8 parallel mappers at once →
  server-side 429 for all; chunked to 3-concurrent with per-agent retry on resume.
