### Key decisions

- **Per-finding adversarial verification, refute-first.** Materially corrected ~40% of findings (line numbers, counts, reversed complexity mapping in pipeline-pkg-4, refuted 7 outright). Worth the token cost — report is high-precision.
- **Refuted claims documented in report §8** so future sweeps don't re-litigate (yaml dep, e2e workspace deps, runtime re-export shims, env-var sprawl all refuted with wiring evidence).
- **Workflow resume caveat learned:** editing a workflow script prompt mid-run invalidates the cache prefix — everything after the first edited agent() call re-runs. Salvaged run-2 results from the task output file and launched a fresh part-2 workflow for missing domains instead of resuming a third time.
- **Workflow args caveat learned:** `args` passed to the Workflow tool arrived as a string, so `args.root` interpolated as `undefined` in prompts. Agents coped via cwd. Hardcode paths in scripts when it matters.
