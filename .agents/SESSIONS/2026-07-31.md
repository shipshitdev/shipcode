### Key decisions
- **`''` means "keep", not "clear".** The renderer only ever holds the redacted
  marker, so treating `''` as a clear let any unrelated routing save silently wipe
  the encrypted webhook. `null` is now the only clear. Documented on both sides so
  the read/write contract cannot drift.
- **Full ancestor walk over first-existing-ancestor.** `existsSync` follows
  symlinks, so `configured -> outside` with an existing `outside/child` lstats as a
  plain directory. Only walking every lexical ancestor catches the escape.
  `isOsPathAliasRoot` keeps `/tmp`, `/var`, `/private/*` working.
- **Verified findings against HEAD, not the bot's diffs.** Several suggestions were
  already stale relative to the branch.
- **Did not widen scope to the macOS symlink bug** (below) — pre-existing on master,
  invisible to CI, and unrelated to this PR's threads.
