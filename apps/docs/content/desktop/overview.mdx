# Desktop App

The ShipCode desktop app is the primary way to run the pipeline. It's an Electron + Vite + React 19 app built on top of the same `packages/pipeline` state machine that powers the CLI, with a rich UI for watching pipelines, triaging issues, editing settings, and reviewing plans and costs.

## Install

```bash
brew tap shipshitdev/shipcode
brew install --cask shipcode
```

Or run from source:

```bash
bun install
bun run dev
```

See [Getting Started](/getting-started) for prerequisites and first-pipeline walkthrough.

## Layout

The app has a fixed left sidebar with projects, a top titlebar, a main content area, and a collapsible terminal drawer at the bottom. The sidebar contains shortcut entries to each of the global views:

| Section | What it does |
|---------|--------------|
| [Mission Control](/desktop/mission-control) | Dashboard across all projects — active runs, recent completions, alerts |
| [Inbox](/desktop/inbox) | Triage queue for failed, verification-exhausted, and awaiting-approval threads |
| [Costs](/desktop/costs) | Per-thread and per-project token + USD aggregation |
| [Skills Editor](/desktop/skills) | Edit the PRD / plan / review / verify prompt skills |
| Project detail | Kanban board, list view, terminal drawer, and issue detail overlay for one project |

## Per-project views

Inside a project, the main content area switches between:

| View | What it does |
|------|--------------|
| [Kanban Board](/desktop/kanban) | Phase-column board for dragging issues through the pipeline |
| List view | Same data as Kanban, flattened into phase-grouped sections (toggle from the Kanban header) |
| [Terminal](/desktop/terminal) | Bottom drawer that streams planner / reviewer / executor / verifier subprocess output |
| Issue detail | Overlay that shows the full issue PRD, generated plan, review round history, diff, and full-screen [Plan Viewer](/desktop/plan-viewer) |

## Settings

The [Settings panel](/desktop/settings) covers General, Pipeline, Models, Notifications, Archived Projects, and Shortcuts — plus the per-project [Project Settings modal](/desktop/project-settings) for overriding the GitHub Projects v2 board URL.
