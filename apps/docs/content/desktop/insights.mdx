# Insights

The project **Insights** tab summarizes activity and spend for one repository.

The view is [`apps/desktop/src/renderer/features/project/ProjectInsights.tsx`](https://github.com/shipshitdev/shipcode/blob/master/apps/desktop/src/renderer/features/project/ProjectInsights.tsx).

## What it shows

- Tokens
- Estimated cost
- Pipeline runs
- PRs opened
- Active days
- Activity heatmap for 30, 90, or 365 days

The heatmap uses the same activity and cost rows as Overview and Costs, scoped to the active project.
