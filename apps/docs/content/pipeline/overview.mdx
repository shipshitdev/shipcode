# Pipeline Overview

The ShipCode pipeline is a state machine that processes GitHub issues through multiple phases.

## Phases

| Phase | Default model | Description |
|-------|---------------|-------------|
| Plan | Opus 4.6 | Rewrites issue into spec + structured plan |
| Review | Codex (high reasoning) — set during onboarding | Adversarial critique, max 2 rounds |
| Execute | Routed per `agent:*` label (claude / codex / openrouter) — configurable in Settings | Implements in isolated git worktree |
| Verify | Opus 4.6 — set during onboarding | Checks diff against acceptance criteria |
| Ship | gh CLI | Push branch, create PR, link to issue |

The planner, reviewer, and verifier models are chosen during `shipcode onboard` (or the desktop onboarding wizard). The executor is additionally editable from the desktop **Settings → Models** panel at runtime. Changing planner/reviewer/verifier post-onboarding currently requires editing the `settings` row in the local SQLite DB.

## State Machine

```
Todo → Planning → Reviewing ⇄ Revising → (Awaiting Approval) → Executing → Verifying → Shipping → Completed
                                                                                                 ↘ Failed
```

- **Awaiting Approval** is skipped unless `requireApproval` is enabled in Settings. When enabled, the pipeline pauses after review and waits for a human to click "Approve" before executing.
- **Revising** loops back to **Reviewing** up to `maxReviewRounds` times (default 2, configurable 1–5).
- **Shipping** runs after **Verifying** and uses `gh` CLI to push the branch, open the PR, and link it back to the issue.
- Any phase can transition to **Failed** on error.

The exact phase enum lives in [`packages/shared/src/types.ts`](https://github.com/shipshitdev/shipcode/blob/master/packages/shared/src/types.ts) as the `ThreadStatus` and `PipelinePhase` unions.

## Autonomous Mode

When triggered by a GitHub issue label, the pipeline runs without human intervention until a PR is created. The only human gate is the PR review itself.
