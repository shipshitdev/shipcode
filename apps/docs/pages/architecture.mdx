# Architecture

ShipCode is a Turborepo monorepo with multiple apps and shared packages.

## Structure

```
apps/
  web/              Marketing site (Next.js + Tailwind)
  desktop/          Electron + Vite + React 19
  cli/              CLI tool (published as 'shipcode' on npm)
  docs/             This documentation (Nextra)
packages/
  pipeline/         Pipeline state machine
  shared/           Types, schemas, constants, design tokens
  agents/           Process manager, prompts, GitHub CLI
  db/               SQLite persistence (node:sqlite)
  git/              Git operations + worktree manager
  ui/               React components
```

## Key Design Decisions

- **`gh` CLI over GitHub API** — no OAuth, uses existing auth
- **Adversarial review** — different model families catch different blind spots
- **PR is the human gate** — fully autonomous until PR creation
- **Fork-point SHA for diffs** — stable diffs even when base branch moves
- **node:sqlite** — built-in Node.js SQLite, no native addon dependencies
